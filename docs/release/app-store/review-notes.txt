WagLock stores a local encrypted library and requires no server account or supplied demo login. On first launch, create a local password of your choice and keep it for review. There is no password reset or hidden review bypass.

Start by creating a note; this requires no photo permission or sample media. New resumes the one unfinished draft, and Done/Save note explicitly saves it. Import a disposable photo/video using Photos or Files to test playback and organization. Create a nested album with a separate album password to check additional protection. Optional Face ID can be enabled in Settings using the current vault password; cancellation does not grant access. Face ID-only albums display a device-bound recovery warning.

The first release locks immediately when backgrounded. Audio import/playback is available; new audio recording and calculator login are deferred. Detected screen recording/mirroring locks the app; stop capture before unlocking. Background/lock and unlock with your chosen password. You may change the main password in Settings; an album or backup password remains independent. Settings > Encrypted backup creates an age-format encrypted backup with a separate password or recovery key, and lets you edit its filename before saving through Files. A cloud destination accepting the file does not establish completed remote upload. The recovery walkthrough is https://github.com/donnellymjd/waglock/blob/main/docs/portable-vault/backup-recovery.md.

All local features are free. No purchases, subscriptions, advertising SDK, hosted content-sharing service or account creation/deletion flow is present. Settings includes privacy, support, source and license links. Earlier WagLock Dev libraries are separate and are not migrated.

Alternative-passcode library (included in this release): while in the primary library, open Settings > Security & access > Set up alternative passcode. Choose a distinct passcode, lock the app and enter it on the ordinary login screen. It opens a separate persistent encrypted library with its own media, notes and protected albums; the primary passcode opens the original library. There is no vault selector on login. Face ID can be explicitly assigned to either library after password verification, with a disclosure warning because biometrics cannot infer the intended library. Verify cancellation stays locked. This privacy feature is disclosed for review and has no review-only bypass. Separate backup exports contain only the selected unlocked library. No forensic deniability claim is made.

The public release does not accept legacy native .encrypted imports or ZNSC v1 streams. Normal Photos/Files imports and documented age backup recovery remain supported; no development-library migration or in-app backup restore is claimed.
