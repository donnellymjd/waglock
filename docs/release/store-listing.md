## Description candidate

Keep your personal photos, videos and files in a local library with its own password. Organize albums with additional passwords and optional Face ID convenience.

WagLock works without a WagLock account. Import from Photos or Files, browse your media, and choose when to share a decrypted copy. Create an optional encrypted backup and save it through the iOS Files interface, including providers you have configured. Independent recovery instructions and open-source tools help you open supported backups on your computer.

All local features are free. There are no VIP unlocks or subscription gates. Keep your passwords and recovery material safe: we cannot reset them or retrieve your library for you.

WagLock is an independent modified fork of the open-source SealedPocket / ZeroNet Space project. It is not the official version and does not imply upstream endorsement. Source code and notices are available in the WagLock GitHub repository.

## Review instructions draft

1. Fresh installation needs no server account or supplied demo login. Create a local password of your choice and retain it for the review; ordinary password verification remains enabled. There is no hidden review bypass.
2. Use disposable photos/files. Import a photo and short video through Photos or Files and confirm viewing/playback. Microphone access is optional for recording; Face ID is optional. Provide sample instructions using the system's supported sources if the review device has no media.
3. Create a parent and nested album. A separately password-protected album requires its own password; the main password does not silently replace it. Face ID-only protection has device-bound recovery warnings.
4. Lock/background/reopen and unlock using the password. Check optional Face ID on supported hardware, including cancellation.
5. Create an encrypted backup with a separately selected export password. Save through Files or cancel the picker. Include final independently verified recovery instructions and documented coverage/resource limits with the submitted version. A system destination accepting a file is not a remote-upload guarantee.
6. Settings provides source, notices, privacy and support information. No purchases, subscriptions, advertising SDK or backend login is required for the inspected candidate.
