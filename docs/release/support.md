# WagLock support

WagLock is in development. A separate WagLock1.0 build50 fresh encrypted candidate passed the owner’s disposable-media, password/Face ID, album and independent backup-recovery checklist. An intermittent note-classification report remains tracked. Existing WagLock Dev libraries are not migrated. An App Store release has not been submitted.

For a bug or question, [open a GitHub issue](https://github.com/donnellymjd/waglock/issues). Include the app version/build, iOS version, a short description and reproduction steps using disposable samples. GitHub issues are public. Do not attach private photos, files, encrypted backups, passwords, recovery keys or unredacted logs. We will not ask you to publish these.

[Backup recovery instructions](../portable-vault/backup-recovery.md) explain independent extraction with the open-source age tool. Keep independent originals until you have verified a complete backup. A vault password is not necessarily an album or export password. Do not uninstall/reset the app as a troubleshooting step for a library you need to preserve.

## Forgotten password

Open **Can’t unlock?** on the locked screen for password-manager, previously enabled Face ID and [desktop backup recovery](../portable-vault/backup-recovery.md) guidance. WagLock cannot recover a forgotten vault password. **Erase WagLock and start over** deliberately destroys all local vault content and app unlock credentials after acknowledgement and typing ERASE; exported backups and originals outside the vault remain separate. Confirm only if you accept losing all local vault content. Reinstalling is not a password reset. Native recovery keys and in-app backup restore are not available.
