# Public encrypted-library backup fixture

Generated by PortableExportSnapshotTests.testEncryptedLibraryBackupFixtureForIndependentRecovery using the actual fresh encrypted mount and draft backend. Every credential and payload is public synthetic test data. Contains actual generated PNG/MOV/WAV/PDF originals, independently protected nested albums, notes, Unicode metadata and an encrypted-vault draft. No owner library, password or phone was accessed.

Run independent recovery with the unmodified official age CLI:

```sh
python3 tools/check_backup_interop.py --fixture tools/fixtures/encrypted-library-backup --age /path/to/age
```

The checker verifies hashes, readable extensions/signatures, notes/drafts/Unicode, both separate album password boundaries and tampering/truncation rejection. This is independent desktop recovery of supported content, not an in-app import/restore or proof of remote cloud-upload completion. Native credentials, device preferences and biometric registrations are not exported. Regenerate all three data/provenance files together from the named test attachments.
